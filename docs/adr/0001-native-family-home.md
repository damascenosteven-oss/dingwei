# 0001 · 家属使用微信原生小程序

## 问题与证据

新仓库只有 README。用户要家人在微信查看位置，并要求先验收项目骨架。参考项目以 Android 手机采集数据、网页展示；当前缺少目标手机锁屏后能持续传输的实测记录。

## Critic Loop

| 方案 | 成本与影响 | 采纳评分 |
| --- | --- | --- |
| 原生家人首页，另设老人端真机验证阶段 | 只引入小程序必需文件。可先验证家人端；后台定位仍需单独实测。 | 95/100，采纳 |
| 直接复用旧网页作为家人端 | 初期界面成本低，仍需适配微信，网页测试难以证明原生入口可用。 | 45/100，拒绝 |
| 维持仅有 README | 改动最少，无法验收可打开的首页或 CI 故障检测。 | 20/100，拒绝 |

## 决定

家人首页只呈现未绑定状态。检查使用 Node.js 内置测试工具；实际显示另以微信开发者工具验证。新仓库不引入老项目的账号、坐标、数据库或设备凭证。
