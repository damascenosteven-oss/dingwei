# 决策记录

| 问题 | 备选与用户决定 | 原因 |
| --- | --- | --- |
| 老人出门携带什么？ | 比较手机小程序、独立手表和现有安卓手机。用户最终明确只带现有手机。 | 希望老人每次出门无需操作。实际型号、系统版本和锁屏稳定性留待真机取证。 |
| 第一期做什么？ | 用户批准先做原生微信家人首页、分步路线和 CI；完整定位功能分阶段实施。 | 先验证项目可打开、可检查，再验证老人手机持续上报。 |
| 如何交付？ | 用户提供 GitHub 仓库并授权上传通过检查的 Issue 分支、跑远端 CI。 | 以最终提交对应的工作流结果交付，后续另行决定合并和发布。 |
